# Memento

Plataforma web para gestionar apuntes de manera legible y práctica: temas por cuaderno, notas con etiquetas, archivos y búsqueda.

Implementación IA (En futuras etapas): Clasificar notas en categorias como formulas, datos historicos...

> Proyecto del curso Taller de Programación.

## Estado actual

### Fase I — Primera entrega
Primera entrega: estructura inicial del repositorio y primera versión de la interfaz (Front-End).

En desarrollo: base de datos, backend y API.

### Fase II — Evolución del prototipo funcional
En esta fase se continúa el desarrollo sobre el **mismo repositorio** de la Fase I. El objetivo es evolucionar la interfaz inicial hacia un prototipo funcional, con navegación entre secciones, funcionalidades principales de gestión de apuntes, organización del código, validaciones básicas y manejo de datos según las necesidades del proyecto.

**Aspectos a desarrollar y verificar en esta fase:**
- Interfaz de usuario para la gestión de apuntes.
- Navegación entre las funcionalidades disponibles.
- Gestión de cuadernos y notas, de acuerdo con lo implementado en el prototipo.
- Organización de componentes y código fuente.
- Validaciones básicas y manejo de errores.
- Manejo de datos y, cuando corresponda, conexión con los servicios del backend.

> **Importante:** Esta sección describe los objetivos de la Fase II, no certifica que todas las funcionalidades estén terminadas. Actualizarla conforme se compruebe el funcionamiento real del proyecto.

## Tecnologías previstas
- Frontend: React (Vite)
- Backend: Spring Boot (java 21)
- Base de datos: MongoDB

## Estructura
```text
memento/
├── frontend/
├── backend/
└── diagrams/
```

La estructura se mantiene en el repositorio original y se organiza conforme avanza el desarrollo.

## Cómo ejecutar el frontend
```bash
cd frontend
npm install
npm run dev
```
Luego abre http://localhost:5173
