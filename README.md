# Memento

Plataforma web para gestionar apuntes de manera legible y práctica: cuadernos por materia, notas con etiquetas, archivos y búsqueda.

> Proyecto del curso Taller de Programación.

## Estado actual
Primera entrega: estructura inicial del repositorio y primera versión de la interfaz (Front-End).
Aún no incluye base de datos, backend ni APIs.

## Tecnologías previstas
- Frontend: React (Vite)
- Backend: Spring Boot (próximas etapas)
- Base de datos: PostgreSQL (próximas etapas)

## Estructura
```
memento/
└── frontend/
```

## Cómo ejecutar el frontend
```bash
cd frontend
npm install
npm run dev
```
Luego abre http://localhost:5173
